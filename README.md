# Dangerous Dave (web build)

Built files of a WebAssembly port of Dangerous Dave (John Romero, Softdisk, 1990),
made from a source reconstruction of the original DOS game.

Play: https://ducky-beep-boop.github.io/dangerous-dave-web/

Controls: arrows move, Ctrl / Z / Space fire, Alt / X jetpack, F1 help,
F2 control panel, F3 restart, F9 pause, F10 or Esc quit.

This repository holds only the build output (static files); the game data is
embedded in `dave.wasm`. The game itself is the work of its original authors.
